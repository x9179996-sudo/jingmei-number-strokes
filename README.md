# 一年級「數字筆順」冒險學習網頁（景美國小專用教材）

本專案是為**臺北市景美國小一年級學生**量身打造的數學領域第一單元學習工具。主要讓低年級學生在家使用平板、手機或電腦自主練習阿拉伯數字 0–10、國字一～十的標準筆順與數字接龍數序，亦支援教室大螢幕觸控示範與 A4 學習單列印。

---

## 🚀 怎麼開啟

1. **直接雙擊開啟（離線可用）**：
   - 點擊雙擊 `index.html` 即可在瀏覽器（Edge、Chrome、Safari、Firefox）直接執行。
   - 支援 `file://` 協定，無須架設本機伺服器、無須連上網際網路、不依賴任何外部 CDN 或第三方 API。
2. **A4 列印版學習單**：
   - 點擊雙擊 `print.html`，或在主程式的家長專區點擊「🖨️ 前往 A4 列印學習單」。
   - 點擊「列印學習單」或按快捷鍵 `Ctrl + P`，排版已針對 A4 紙張最佳化，列印時自動隱藏工具列。
3. **執行自動化單元測試**：
   - 開啟終端機執行：
     ```bash
     node tests/selftest.js
     ```

## 📜 筆順依據與官方標準核對

### 1. 阿拉伯數字 0–10（依據翰林版一年級數學課本）
完全依據翰林版一年級數學第一單元規格製作，不擅自更改：
- **0**：1 筆。從上方中間起筆，逆時針繞一圈回到起點。
- **1**：1 筆。由上往下一豎。
- **2**：1 筆。從左上起筆，往右上彎出順時針弧線，斜向左下到底，再往右一橫。
- **3**：1 筆。從左上起筆，順時針畫上半弧到中間，再順時針畫下半弧，到左下收筆。
- **4**：2 筆。① 從上方往左下斜，到底後轉向右一橫；② 右側一豎，由上往下穿過橫線。上方開口，兩筆頂端不相連。
- **5**：2 筆。① 從左上往下一短豎，接著往右繞出下方大弧（順時針），到左下收筆；② 上方一橫，從豎的頂端由左往右。
- **6**：1 筆。從右上起筆，沿左側弧線往下，到底部後往右再往上，繞成下方小圈收筆。
- **7**：2 筆。① 左上一小豎，由上往下（翰林版特色，確實呈現）；② 一橫由左往右，到右端轉斜向左下。
- **8**：1 筆。從右上起筆，往左繞過頂部（逆時針），經過中心往右下，順著右側往下繞過底部（順時針），從左側往上經過中心，回到起點。
- **9**：1 筆。從右上起筆，逆時針繞一圈回到右上，再往下直直寫到底。
- **10**：2 筆。① 1，由上往下；② 0，從上方起筆逆時針繞一圈。

## 💡 自行決定事項（設計與實作細節）

1. **判斷門檻分級（寬鬆／標準）**：
   - 考量臺北市景美國小一年級新生手部小肌肉協調仍在成長，系統預設為「寬鬆（loose）」模式：
     - 起點容許誤差：格寬 22%（22 單位）。
     - 形狀平均距離：格寬 19%（19 單位）。
     - 最小長度比率：標準長度的 50% 以上。
   - 「標準（standard）」模式可於家長專區切換：起點 ≤ 18%、形狀 ≤ 15%、長度 ≥ 60%。
2. **閉合曲線（0 與 8）之逆時針與順時針方向判別**：
   - 一般開放曲線判定條件為「終點比起點更接近標準終點」。然而閉合曲線起終點重合，為避免逆向書寫被誤判通過，引擎在閉合曲線判定時，特別加入曲線四分之一處（第 8 點與第 24 點）方位距離檢核，確保 0 必須由頂部逆時針繞行、8 必須由右上往左逆時針繞過頂部。
3. **無挫折的友善錯誤引導**：
   - 寫錯時不扣分、不出現刺耳紅叉、不發出負面蜂鳴聲。
   - 使用者筆跡會柔和淡出消失，起點綠點閃爍並顯示鼓勵式提示（如「從綠點開始喔」、「順著箭頭寫寫看」）。
   - 當同一筆連續寫錯兩次時，自動播放該筆畫的單步示範動畫。
4. **海洋冒險主題與寶物箱**：
   - 採用小帆船穿梭於海島之間的主題（遠離小火車站造型）。
   - 設計原創 SVG 小海龜嚮導與 27 款海洋寶物（七彩貝殼、珍珠、海星、珊瑚等），每過一關即可開箱收集。島嶼全部滿星時升起金色島旗。
5. **注音字型與離線字型子集**：
   - 介面採用 ButTaiwan 基於 SIL Open Font License 開源發布的「芫荽注音 (BpmfIansui)」。
   - 使用 `fonttools.subset` 精心提煉出涵蓋全部介面標籤、數字、注音符號與教育用字之子集（僅約 135 KB），保證純本機離線載入且無版權疑慮。
6. **防誤觸長按進入機制**：
   - 進入家長專區需長按齒輪圖示達 2 秒，圓環動態倒數指示，防止一年級小朋友誤觸跳出或修改設定。
   - 內建 6 位小朋友獨立存檔切換，各具不同海洋動物頭像與個別進度紀錄。
7. **老師模式（大螢幕白板專用）**：
   - 一鍵解鎖全部 27 個關卡、不計分、示範動畫新增「👉 下一筆示範」按鈕，方便教師在觸控大螢幕上一筆一筆拆解講解。

## 🛠️ 本次修改紀錄（Revision Log）

依據修正任務規格，本版本針對引擎、資料、介面、列印版與測試完成以下 8 項核心修正（不添加無關新功能）：

1. **曲線平滑（Catmull-Rom Spline）**：
   - 於 `engine/stroke-engine.js` 實作純函式 `smoothPath(points, subSegments = 8)`，利用 Catmull-Rom 演算法將控制中線補點為平滑連續曲線（閉合曲線自動首尾平滑閉合，開放曲線端點切線外推）。

   - 筆跡判定時，標準中線亦先平滑補點再重新取樣成 32 點，使判定基準與肉眼所見完全一致。字形資料檔維持中線關鍵點結構。

2. **筆畫線寬動態比例**：

4. **「寫」步驟之位置錨定機制（Position Anchoring）**：

## 🛠️ 第三輪修改紀錄（Round 3 Revision Log）

本輪修正針對「判定太鬆」、「筆順編號重疊」、「海圖島名被裁切與手機適配」以及「去除介面工程用語」等 4 項具體問題進行深化：

1. **嚴格筆跡判斷（修正判斷太鬆問題）**：
   - **shapeMaxDist 門檻回調**：寬鬆模式之形狀平均距離門檻由 22 回調為 19（標準模式 15）。
   - **最大偏離檢查（Max Deviation Check）**：
     - 將學童筆跡與標準中線取樣為 32 點逐點比對，最大距離不得超過門檻。
     - 門檻設定於 `THRESHOLDS`：寬鬆模式 `loose.maxDevDist = 34`、標準模式 `standard.maxDevDist = 28`。
     - 失敗提示引導：「筆畫跑太遠囉，沿著虛線寫寫看！」。
   - **四分段向量方向檢查（Segment Direction Cosine Check）**：
     - 將 32 點平分為 4 段（0–8、8–16、16–24、24–31 點），計算學童筆跡每段端點向量與標準筆畫同段向量之餘弦相似度 $\cos(\theta)$。
     - 門檻：寬鬆模式 `loose.minSegCos = 0.2`、標準模式 `standard.minSegCos = 0.4`。
     - 排除保護：標準筆畫該段弦長 $< 6.5$ 單位跳過不比；整體長度 $< 25$ 單位的短筆畫（如六的點、7 的短豎）或「豎彎」等轉折段跳過，避免數值噪聲誤判。
     - 失敗提示引導：「方向不太對，順著箭頭寫寫看！」。
   - 寫模式位置錨定在判斷前平移標準筆畫，閉合曲線與開放曲線均能完美判別。

2. **筆順示範與列印版編號防重疊（print.html & index.html）**：
   - 實作純函式 `StrokeMath.computeStrokeGuides(glyph)`：
     - 每一筆在起點位置加上同色小箭頭，指向平滑後第 0 點至第 4 點的書寫切線方向。
     - 圓圈編號位置依該筆起始方向的反方向退後 9 個單位放置。
     - 自動防重疊碰撞推開機制：若兩個編號距離小於 8 個單位，後者自動沿垂直方向推開 8 個單位，確保 5、7、四、五、六等起點密集之字形編號彼此清晰分明。
   - `print.html` 的放大示範格與 `index.html` 第一步驟「看」之示範畫布完全共用此防重疊編號與起筆箭頭系統。

   - **島名標籤排版**：標籤長度隨字數彈性展開，字級均 $\ge 18\text{px}$（粗體），標籤完全收納於畫布可視範圍內，絕不切字。
